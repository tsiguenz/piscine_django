Django Template Engine

Django’s template engine generates dynamic HTML by combining static HTML with data sent from the server (the context).

Context Variables

Variables passed from the view are displayed using double curly braces.

Blocks

Blocks define sections of a template that child templates can override.

Loops (for ... in)

Loops are used to iterate over lists of data.

If Conditions

If statements display content depending on a condition.
